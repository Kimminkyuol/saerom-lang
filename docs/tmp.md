# 새롬 문법 명세서

예제는 [예제](../examples/) 디렉터리에서 확인할 수 있습니다.

## 문장

문장은 마침표(`.`)로 끝납니다. 블록은 콜론(`:`)으로 열고 들여쓰기로 구획을 묶습니다.
마침표나 콜론으로 끝나지 않은 줄은 다음 줄로 이어집니다.
`#`부터 줄 끝까지는 주석으로 처리됩니다.

## 리터럴 및 자료형

* **숫자:** `3`, `-1.5`
* **문자열:** `"글"`
* **논리값:** `참`, `거짓`
* **기타:** `없음`(Null/None), 빈 배열 `목록`, 빈 객체 `사전`

괄호를 사용하는 리터럴 표현은 제공하지 않습니다. 목록은 `3과 1과 2`처럼 나열하여 생성하며, 사전은 필드에 값을 할당하여 채웁니다.

문자열 내부의 `{ }` 표현식은 보간(Interpolation)되어 평가됩니다. 이스케이프 문자는 `\n`, `\t`, `\{`, `\}`를 지원합니다.

지원하는 자료형은 `정수`, `실수`, `문자열`, `논리값`, `목록`, `사전`, `없음`이며, `<값>의 자료형` 형태로 타입 이름을 조회할 수 있습니다.

## 조사 (매개변수)

매개변수는 조사로 구분하므로 인자의 전달 순서가 자유롭습니다. 단, 단일 함수 정의 내에서 동일한 조사를 중복해서 사용할 수 없습니다.


```

"안녕"을 "새롬"에게 전한다.
"새롬"에게 "안녕"을 전한다.

```

**사용 가능한 조사:** `은/는`, `이/가`, `을/를`, `에`, `에게`, `에서`, `으로/로`, `의`, `보다`, `와/과`, `마다`, `만큼`, `부터`, `까지`

## 어미 (함수 호출 패턴)

동사에 결합하는 어미에 따라 해당 호출문의 역할과 반환 형태가 결정됩니다.

| 어미 | 역할 | 예시 |
|---|---|---|
| `-ㄴ다` | 실행문 종료 | `출력한다` |
| `-고` | 실행문 연결 | `출력하고` |
| `-ㄴ`, `-는` | 반환값 (식) | `더한 값` |
| `-ㄴ지` | 논리값 (조건식) | `큰지` |
| `-면` | 조건절 종료 | `크면` |
| `-거나` | 조건절 연결 (OR) | `크거나` |
| `-지 않-` | 부정 표현 | `크지 않으면` |

조건절을 `-고`로 연결하면 논리곱(AND)을 의미합니다. 반환값 위치의 `값` 키워드는 생략 가능합니다.
`이다` 서술어의 활용형은 `이다`, `인`, `인지`, `이면`, `이고`, `이거나`, `라는`을 지원합니다.

## 함수 및 속성 정의

기본적으로 `<구절>* <서술어>라는 것은:` 구조를 가지며, 구절은 `<변수명> <조사>`의 쌍으로 구성됩니다.

| 서술어 형태 | 호출 형태 |
|---|---|
| 서술형 (`구하다`) | `구한다`, `구한 값` |
| `<이름>이다` | `X가 <이름>인지`, `만약 X가 <이름>이면` |
| `<이름>` (속성) | `<소유자>의 <이름>`. 구절은 `<소유자>의` 하나만 허용 |
| `...되다` (피동형) | `<값>이 ...된 <나머지 인자>` |

> **주의:** `<이름>이다` 형태의 정의는 다른 활용형으로 확장하여 호출할 수 없습니다.

정의 내부에서 변수에 값을 할당하면 해당 정의 스코프에 속하는 **지역 변수**가 됩니다. 외부 스코프에 존재하는 동일한 이름의 변수 값은 변경되지 않습니다.

수학을 불러온다.                        # 수학의 원주율, 2를 10으로 수학의 거듭한 값

## 내장 함수 (Built-in Functions)

| 구문 | 설명 |
|---|---|
| `<값>을 출력한다` | 표준 출력 |
| `<메시지>로 종료한다` | 프로세스 종료 (종료 코드: `1`) |
| `<값>을 복사한 값` | 목록·사전 객체의 깊은 복사(Deep Copy) |
| `<값>을 <자료형>로 바꾼 값` | 명시적 형변환 |
| `<값>에 <값>을 더한 값` | 목록·문자열의 경우 결합(Concat) |
| `<값>에서 <값>을 뺀 값` | 산술 뺄셈 |
| `<값>에 <값>을 곱한 값` | 산술 곱셈 |
| `<값>을 <값>으로 나눈 값` | 산술 나눗셈 (`나눈 나머지` 연산도 지원) |
| `<값>이 <값>보다 큰지` | 대소 비교 (`작은지` 연산도 지원) |
| `<값>이 <값>과 같은지` | 동등 비교 |
| `<경로>를 <모드>로 연 값` | 모드: `"읽기"`, `"쓰기"`, `"추가"` |
| `<파일>에서 <크기>만큼 읽은 값` | 바이트 단위 읽기 |
| `<파일>에 <데이터>를 쓴 값` | 기록한 바이트 수 반환 |
| `<파일>을 닫는다` | 파일 스트림 해제 |

파일 객체는 정수 형태의 파일 디스크립터(FD)입니다. `0`(표준 입력), `1`(표준 출력), `2`(표준 에러)는 별도의 오픈 과정 없이 즉시 사용할 수 있습니다.

| 필드 / 속성 | 대상 자료형 | 설명 |
|---|---|---|
| `자료형` | 모든 객체 | 데이터 타입 반환 |

| 파생 필드 | 사용자 정의 객체 | 커스텀 정의 속성 |

## 주요 유의 사항

- **참조 전달:** 목록과 사전은 기본적으로 참조(Reference)로 전달됩니다. 독립된 객체가 필요한 경우 `복사한 값`을 통해 복제해야 합니다.
- **가변 vs 불변 연산:** `<목록>에 <값>을 더한다`는 원본 목록을 수정하는 인플레이스(In-place) 연산이며, `더한 값`은 새로운 복사본을 생성하여 반환합니다.
- **산술 연산 타입:** 정수 간 연산 결과는 정수이며, 피연산자 중 하나라도 실수이면 결과는 실수입니다. 나눗셈의 경우 나누어떨어지면 정수 타입을 반환합니다.
- **비교 연산 제한:** `크다`, `작다` 연산은 동일한 타입(수치형 끼리 또는 문자열 끼리) 간에만 가능합니다. `같다` 동등 비교는 정수와 실수 간 비교를 허용합니다.
- **기본 반환값:** 별도의 반환값을 명시하지 않고 종료되는 함수/정의의 반환값은 `없음`입니다.
- **디버깅 및 에러:** 런타임 에러 발생 시 메시지를 표준 에러(stderr)로 출력하고 종료 코드 `1`을 반환합니다. `-g` 옵션으로 컴파일하면 상세 스택 트레이스(Traceback)가 함께 제공됩니다.
