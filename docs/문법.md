# 새롬 문법

예제는 [예제](../examples/)에서 확인할 수 있습니다.

## 문장

- 문장은 마침표로 끝냅니다.
- 쌍점과 들여쓰기로 블록을 구분합니다.
- 마침표나 쌍점으로 끝나지 않은 줄은 다음 줄로 이어집니다.
- `#`부터 줄 끝까지는 주석으로 처리됩니다.

## 리터럴 및 자료형

- 숫자: `3` `-1.5`
- 문자열: `"글"`
- 논리값: `참`, `거짓`
- 없음: `없음`
- 빈 묶음: `묶음`
- 묶음: `3과 1과 2`

문자열 내부의 `{ }` 표현식은 보간됩니다. 이스케이프는 `\n` `\t` `\{` `\}`를 지원합니다.

자료형은 `정수` `실수` `문자열` `논리값` `묶음` `없음`이며 `<값>의 자료형`으로 조회할 수 있습니다.

## 묶음

```
빈것은 묶음이다.
수들은 3과 1과 2이다.
주소는 도시가 "서울"이고 국가가 "한국"인 묶음이다.

수들에 4를 추가한다.
수들의 1번째를 제거한다.
주소의 우편번호는 "06234"이다.
주소의 국가를 제거한다.
```

`길이`는 인덱스 자리 개수만 반환합니다.

## 조사 (매개변수)

매개변수는 조사로 구분됩니다. 한 정의에서 같은 조사를 두 번 사용할 수 없습니다.

```
"안녕"을 "새롬"에게 전한다.
"새롬"에게 "안녕"을 전한다.
```

사용 가능한 조사: `은/는` `이/가` `을/를` `에` `에게` `에서` `으로/로` `의` `보다` `와/과` `마다` `만큼` `부터` `까지`

## 어미 (함수 호출)

| 어미 | 역할 | 예시 |
|---|---|---|
| `-ㄴ다` | 실행문 종료 | `출력한다` |
| `-고` | 실행문 연결 | `출력하고` |
| `-ㄴ`, `-는` | 값 | `더한 값` |
| `-ㄴ지` | 논리값 | `큰지` |
| `-면` | 조건절 종료 | `크면` |
| `-거나` | 조건절 연결 | `크거나` |
| `-지 않-` | 부정 | `크지 않으면` |

조건절을 `-고`로 연결하면 `그리고`를 의미합니다.
`이다`는 `이다` `인` `인지` `이면` `이고` `이거나` `라는`로 활용합니다.

## 구문

```
<이름>은 <값>이다.
<이름>의 <필드>는 <값>이다.  # 묶음
<이름>의 <필드>는 <값>이고 <필드>는 <값>이다.

<매개변수> <동사>ㄴ다.
<매개변수> <동사>고 <인자들> <동사>ㄴ다.

만약 <조건>:
아니고 만약 <조건>:
아니면:

<시작>부터 <끝>까지 <간격> 간격의 <변수>마다 반복한다:
<조건> 동안 반복한다:
빠져나간다.
넘어간다.

<값>을 반환한다.
```

`간격`의 기본값은 1입니다. 조건에서 주어를 생략하면 앞 절의 주어로 처리됩니다.

```
만약 수가 3보다 크고 5보다 작으면:
```

비교 연산에는 `이상` `이하` `초과` `미만`을 사용할 수 있습니다. `만약 점수가 90 이상이면:`

## 정의

기본적으로 `<구절>* <머리>라는 것은:`의 구조를 갖습니다. (구절은 `<이름> <조사>`의 쌍으로 구성됩니다.)

| 서술어 형태 | 호출 형태 |
|---|---|
| 사전형 (`구하다`) | `구한다`, `구한 값` |
| `<이름>이다` | `X가 <이름>인지`, `만약 X가 <이름>이면` |
| `<이름>` | `<소유자>의 <이름>`, `<소유자>의` |
| `...되다` | `<값>이 ...된 <나머지 인자>` |

## 모듈

```
수학을 가져온다.                         # 전체
수학에서 절댓값과 거듭제곱하다를 가져온다.   # 일부
```

소스 파일과 동일한 디렉터리에 위치한 `<모듈>.sr` 파일을 탐색합니다.
가져온 이름은 그대로 사용하며, 전체를 가져온 경우 `<모듈>의 <이름>`으로도 접근할 수 있습니다.
이름이 겹치면 이 파일에서 정의한 쪽이 우선합니다.

## 내장 동사

| 구문 | 비고 |
|---|---|
| `<값>을 출력한다` | |
| `<메시지>로 종료한다` | 종료 코드 `1` |
| `<값>을 복사한 값` | 묶음의 깊은 복사 |
| `<값>을 <자료형>로 바꾼 값` | 명시적 형변환 |
| `<값>에 <값>을 더한 값` | 수, 문자열 |
| `<묶음>에 <값>을 추가한다` | 마지막 자리에 추가 |
| `<묶음>의 <자리\|명칭>를 제거한다` | |
| `<값>에서 <값>을 뺀 값` | |
| `<값>에 <값>을 곱한 값` | |
| `<값>을 <값>으로 나눈 값` | `나눈 나머지` |
| `<값>이 <값>보다 큰지` | `작은지` |
| `<값>이 <값>과 같은지` | |
| `<경로>를 <방식>으로 연 값` | `<방식>`: `"읽기"` `"쓰기"` `"추가"` |
| `<파일>에서 <수>만큼 읽은 값` | 바이트 수 |
| `<파일>에 <글>을 쓴 값` | 쓴 바이트 수 |
| `<파일>을 닫는다` | |

`<파일>은` 정수 서술자입니다. `0`(표준 입력), `1`(표준 출력), `2`(표준 오류)를 사용할 수 있습니다.

## 필드

| 필드 | 대상 자료형 | 비고 |
|---|---|---|
| `자료형` | 모든 자료형 | |
| `길이` | 묶음, 문자열 | |
| `<수>번째`, `<이름>번째` | 묶음, 문자열 | 1-based 인덱스 |
| `명칭` | 묶음 | 명칭을 담은 묶음 |
| 파생 필드 | 사용자 정의 | |

## 유의 사항

- 묶음은 참조로 전달됩니다.
- 정수간 연산의 결과는 정수, 하나라도 실수면 실수입니다. 나눗셈은 나누어 떨어지면 정수입니다.
- `크다` `작다`는 수 또는 문자열 간에만 가능합니다. `같다`는 정수와 실수간 비교가 가능합니다.
- 반환하는 값이 없는 함수의 값은 `없음`입니다.
- 실행 중 오류는 표준 오류로 출력하고 종료 코드 1을 반환합니다. `-g`로 컴파일하면 오류 경로 추적이 함께 제공됩니다.
