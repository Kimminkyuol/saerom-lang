# 새롬

한국어 문법을 따르는 프로그래밍 언어.

```
사람에게 인사를 건네다라는 것은:
    "{인사}, {사람}님.\n"을 출력한다.

"안녕"을 "새롬"에게 건넨다.
"새롬"에게 "안녕"을 건넨다.
```

## 실행

```
saeromc <파일.sr> [-o <출력>] [-O0] [-g]
saeromc --check <파일.sr>
saeromc --dump-types <파일.sr>
saeromc --emit-llvm <파일.sr>
```

## 빌드

```
make
make test
```
